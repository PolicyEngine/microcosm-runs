Read graph documents from the collector's Orrery read service when `MICROCOSM_RUNS_GRAPH_SOURCE` is `collector`, with microcosm-runs' own keyless Google identity, falling back to the publication store for runs the collector has no document for. Each file is checked against its `ETag` and listed SHA-256 before it is sent, and only public documents are shown. The viewer now shows each graph document's provenance and marks documents rebuilt from past builds as reconstructed.
