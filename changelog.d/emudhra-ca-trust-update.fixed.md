The route handlers no longer trust the compromised eMudhra CA roots. When a server instance starts, `instrumentation.ts` removes emSign ECC Root CA - G3 and AAA Certificate Services from Node's default CA list, because Vercel Functions still run a Node.js 24 release whose compiled-in list contains the emSign root. CI and the production deploy job now use Bun 1.4.4, which rejects those roots, instead of 1.4.2.
